# Odisha Bus Playlist v2

Immersive night-bus visual experience using the YouTube IFrame Player API.

## Start
npm install
npm run dev

Then visit http://localhost:3000

Playlist: PL_Dem1ipPjIj_etHyVG_peyth4K1ZBNFW

The project uses an original visual treatment: bus-window scenery, rain, road motion, warm cabin lighting, ticket-style typography and responsive controls.
